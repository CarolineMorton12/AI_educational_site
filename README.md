# Neural Network from Scratch
This website includes:
-  a neural network from scratch, which predicts handwritten numbers with associated confidence
- information on AI and how the neural network works
- a quiz to test the users understanding of AI

This project was made for a component for the Computer Science A-Level, and overall got an A* (top possible grade).

# Running
Clone the repository and download the dependencies using poetry:

```bash
poetry install --no-root
```

Then, run the server:
```bash
poetry shell
python main.py
```

The weights are already given in various `.csv` files to save time.
